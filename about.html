How it works

A little about what the bars are showing.

Try the visualizer

Choose an audio file on the Visualizer page and press play. The bars respond to the sound while it plays.

Go to the visualizer →

Where the bars come from

The Web Audio API analyzes the playing audio and provides frequency values. The page draws those values as bars on a canvas. Taller bars represent stronger values in those frequency ranges.

Made with

  • HTML for the page structure
  • CSS for the notebook-inspired appearance
  • JavaScript, Canvas, and the Web Audio API for the visualizer
