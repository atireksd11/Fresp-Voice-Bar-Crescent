# Sound Sketchbook

A browser music visualizer. Choose an audio file from your device, play it, and watch frequency bars respond to the sound.

## Run locally

Open `index.html` in a browser. If your browser blocks audio features from a local file, run the folder with VS Code Live Server and open its local preview.

## Built with

- HTML
- CSS
- Javascript 
- Canvas and the Web Audio API
